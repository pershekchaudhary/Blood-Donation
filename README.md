# SBDERS

SBDERS is a Laravel 12, Inertia.js, and React starter for a blood-donation platform. The current implementation includes registration and login, password reset, profiles, role-specific dashboards, and role-based dashboard access.

The donor, requester, hospital, and admin dashboards are currently account overviews. Blood-request creation, donor matching, hospital approval tools, and donation tracking are not implemented yet.

## Setup

See [SETUP.md](SETUP.md) for installation, database configuration, and development commands. SQLite is the default database; MySQL can also be configured there.
